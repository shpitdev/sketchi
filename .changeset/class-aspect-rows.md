A class diagram whose export reads wider than 2.4:1 now tries a placement in which a whole hierarchy steps a row down beside another. It keeps that placement only when it draws no more crossings, reader findings, detours or hugging lines and no longer a side. A two-interface observer pattern goes from 2.6:1 to 1.3:1. A class at the end of a row with no line to another row, such as an enumeration that only an Order depends on, now sits beside its neighbor instead of past a wide empty gap.
