Gantt charts name every task in a table left of the plot: a name column, indented under phase headers, beside the date column, with a light rule between rows so each name reads against its bar. The plot holds only bars, diamonds and dependency arrows, so arrows take forward routes where names once stood in the way. In Excalidraw, a bar dragged to new dates leaves its name and dates in the table.
