ER key rows that many relationships share now read as one highlighted row, and their lines run straighter. When a row grows to give each relationship end its own port, it grows by exactly one line for each end past the first. A light tint, a paler shade of the name band, spans the row across the table, and the field stays centred in it. Each end meets a line of its own inside the tint. Before, the field sat in a tall, blank row that read like empty fields. With the ends a full line apart, a line that is level with its partner now runs straight. In a SaaS workspace schema, the line from `organizations.id` to `subscriptions.organization_id` used to drop about 140 px below both rows and climb back. It now runs straight across.
