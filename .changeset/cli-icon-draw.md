`sketchi icon draw FILE --name NAME` draws a logo (SVG, PNG, JPEG or WebP) as a hand-drawn Sketchi icon through the public icon service, with no account, and writes `NAME.excalidrawlib`, `NAME.28.png`, `NAME.112.png` and `NAME.recipe.json`. A folder draws every logo in it and adds one `.excalidrawlib` pack; `--publish` adds each icon to the public community set at icons.sketchi.app with the judge's verdict.
