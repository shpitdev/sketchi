DESCRIPTION
  Strictly offline recovery. Archive the current full state first, then restore revision N byte-for-byte without consuming it and commit at the next monotonic revision. Full snapshots restore artifacts and authority without rebuilding; legacy document-only revisions rebuild only while the record remains canonical.

USAGE
  sketchi restore [flags] <diagram-id>

ARGUMENTS
  diagram-id string

FLAGS
  --revision N    Archived revision number to restore without consuming it.

INHERITED FLAGS
  --output text|json    Result presentation format. (choices: text, json)

GLOBAL FLAGS
  --help, -h                                          Show help information
  --version, -v                                       Show version information
  --completions <bash|zsh|fish|powershell|sh|pwsh>    Print shell completion script (choices: bash, zsh, fish, powershell, sh, pwsh)
