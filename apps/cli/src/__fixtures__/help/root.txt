DESCRIPTION
  Describe a diagram and get a validated PNG plus an editable local record.

Start here:
  sketchi generate --prompt "Map our release approval flow"

The PNG is written to <generated-id>.png in the current directory. Use --format or --dest to
choose another artifact or destination. Run sketchi docs for complete agent and automation contracts.

USAGE
  sketchi <subcommand> [flags]

FLAGS
  --output text|json    Result presentation format. (choices: text, json)

GLOBAL FLAGS
  --help, -h                          Show help information
  --version, -v                       Show version information
  --completions <bash|zsh|fish|sh>    Print shell completion script (choices: bash, zsh, fish, sh)

SUBCOMMANDS
  generate    Generate, persist, and export a PNG from one prompt.
  docs        Print complete agent and automation documentation.
  create      Create a local diagram from canonical JSON.
  show        Inspect one local diagram.
  edit        Replace a canonical diagram document.
  patch       Apply semantic edits to a stored diagram.
  list        List local diagrams.
  restore     Restore a retained diagram revision.
  share       Share an encrypted Excalidraw snapshot.
  pull        Pull browser edits from an Excalidraw link.
  export      Export scene, Excalidraw, or PNG bytes.
