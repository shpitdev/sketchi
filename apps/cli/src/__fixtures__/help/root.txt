  sketchi
  Excalidraw diagrams from a description.

START HERE
  sketchi generate  interactive
  sketchi generate --prompt "Map release approval with pass and revise branches"
  Writes <generated-id>.png in this directory. No account or API key needed.
  canvas    Build and export a typed Universal CanvasSpec.
  icon      Hand-draw a logo as an Excalidraw icon: icon draw FILE.

WORK WITH A DIAGRAM
  list      Find past diagrams, newest first. Add words to search.
  copy      Copy a PNG to the clipboard; the newest by default.
  show      Inspect a local diagram.
  revise    Change it with a request.
  edit      Change a flowchart by id, or replace a document.
  export    Write PNG, Excalidraw, or scene bytes.
  share     Create an encrypted Excalidraw link.

sketchi docs for every command.  Add --output json for automation.
